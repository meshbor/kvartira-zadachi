# Приём к Алексею Пуликову

Терминал талонов в духе Сбера и Почты. Команде нужна только ссылка на сайт — ничего настраивать не надо.

- **Записаться** — выдаёт талон `АП-001`, `АП-002`…
- **Проверить очередь** — табло, кто сейчас у окна и сколько человек впереди
- Раз в сутки, в `00:00` по Москве, очередь обнуляется

## Как запустить

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

- `/` — терминал записи, его и скидываете команде
- `/window` — служебное окно Алексея, вход по паролю `pulekov`
- `/hub` — прежний семейный стол

## Команде

После мержа в `main` откроется обычный production-сайт Vercel. В чат команде кладёте **только эту ссылку**. Никаких URL Redis и токенов людям отправлять не нужно: они просто открывают сайт и берут талон.
