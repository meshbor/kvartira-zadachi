# kvartira-zadachi

Приватный репозиторий по квартире: чеклист задач и бриф отделки кухни, прихожей и гостиной.

## Что открывать

| Файл | Зачем |
| --- | --- |
| [`index.html`](index.html) | Презентация: вердикт, рендеры, планы, смета. Открыть в браузере. |
| [`DESIGN.md`](DESIGN.md) | Полный специалистский бриф: материалы, размеры, где купить, цены в ₽. |
| [`design/plans/`](design/plans/) | SVG-планы сверху с размерами в метрах. |
| [`design/renders/`](design/renders/) | Концепт-картинки (сжатые). |

Ванные, спальня и детская в этот бриф не входят: штукатурка там уже сделана, санузлы — отдельный этап.

## Как смотреть планы

Масштаб подписан на каждом чертеже (кухня и гостиная 1:50, прихожая 1:40). Размеры — рабочие гипотезы по фото, до сверки с планом Paint.
