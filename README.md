# Гуляй, СПб

Утренний дайджест для многодетных семей: что нового появилось в Петербурге в парках, скверах, дворах, на площадках и набережных.

Интерфейс сделан как чат на компьютере. Утром открываете страницу — бот уже собрал свежие новости и раскладывает их по темам и районам.

## Что внутри

- Сбор лент Google Новостей и «Канонера» по паркам, площадкам, дворам и набережным
- Фильтр только прогулочных мест: без зарядок, криминала и чужих городов
- Утренний чат: «парки в Приморском», «площадки», «что нового сегодня»
- Карточка новости с районом, источником и ссылкой
- Ссылки на карты, чтобы сразу прикинуть маршрут

## Как запустить

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Лента обновляется каждые 30 минут при открытии страницы.

## Публикация на Vercel

```bash
npx vercel --prod
```

Если деплой создан без аккаунта, его нужно закрепить за своим Vercel, иначе ссылка пропадёт через час.
