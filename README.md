# Электронная очередь: Записать к Алексею П.

Терминал талонов в духе Сбера и Почты. Большой заголовок, две кнопки, табло окна.

- **Записаться** — выдаёт талон `АП-001`, `АП-002`…
- **Проверить очередь** — табло, кто сейчас у окна и сколько человек впереди
- Раз в сутки, в `00:00` по Москве, очередь обнуляется

Семейный дайджест никуда не делся: [http://localhost:3000/hub](http://localhost:3000/hub).

## Как запустить

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

- `/` — терминал записи
- `/window` — окно оператора, кнопка «Следующий»
- `/hub` — прежний семейный стол

## Публикация на Vercel

```bash
npx vercel --prod
```

Чтобы очередь была общей на всех инстансах, задайте `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`. Без Redis терминал всё равно работает и сам сбрасывается в полночь, но состояние живёт в памяти функции.

Крон `0 21 * * *` бьёт в `/api/queue/reset` — это 00:00 МСК. Дополнительно очередь лениво обнуляется при первом запросе нового дня.
