# Семейный стол

Три раздела в одном месте, переключение табами:

1. **Многодетные** — утренние новости про выплаты, жильё и льготы
2. **Новые пространства** — что нового в парках, дворах и на площадках Петербурга
3. **Нацпроекты** — структурированный список национальных проектов 2025–2030

## Как запустить

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

- `/?tab=family` — многодетные
- `/?tab=spaces` — новые пространства
- `/?tab=projects` — нацпроекты

Ленты новостей обновляются каждые 30 минут при открытии страницы.

## Публикация на Vercel

```bash
npx vercel --prod
```

Если деплой создан без аккаунта, его нужно закрепить за своим Vercel, иначе ссылка пропадёт через час.
