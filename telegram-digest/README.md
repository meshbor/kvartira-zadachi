# Утренний дайджест в Telegram

Личный бот: раз в день собирает новости про многодетные семьи, выплаты и льготы и присылает одну сводку.

Это не «аккаунт, который сидит во всех ваших чатах». Обычный Bot API видит только то, что сам сходил забрать: RSS и публичные превью каналов `t.me/s/...`.

## Как запустить

1. Напишите [BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.
2. В этой папке:

```bash
cp .env.example .env
```

3. Вставьте токен в `TELEGRAM_BOT_TOKEN`. Файл `.env` в git не попадает, агент его не читает.
4. Установите зависимости и запустите бота:

```bash
npm install
npm start
```

5. Напишите боту `/start`. Он покажет **chat id**. Положите его в `TELEGRAM_CHAT_ID` и перезапустите процесс.
6. `/digest` собирает сводку сразу. По расписанию — каждый день в 07:30 по Москве.

Одноразовая отправка (для cron на сервере):

```bash
npm run digest
```

Проверка без отправки и без токена:

```bash
npm run digest -- --dry-run
```

Статус секретов без их значений:

```bash
npm run env:status
```

Печатает только `"set"` / `"missing"`.

## Что лежит в `.env`

| Переменная | Зачем |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Ключ Bot API от BotFather |
| `TELEGRAM_CHAT_ID` | Куда писать. Без него бот никому не шлёт дайджест |
| `DIGEST_CRON` | Расписание, по умолчанию `30 7 * * *` |
| `DIGEST_TIMEZONE` | По умолчанию `Europe/Moscow` |
| `DIGEST_LOOKBACK_HOURS` | Окно сбора, по умолчанию 24 часа |
| `DIGEST_EXTRA_KEYWORDS` | Дополнительные слова через запятую. Любое из них само по себе тащит новость в дайджест — не ставьте одно «Петербург» |

## Источники

Список в `data/sources.json`:

- RSS: РИА, ТАСС, Интерфакс, Клерк. Дальше фильтр по теме.
- HTML: пресс-центр Социального фонда.
- `telegram`: публичные каналы, сейчас `@sfr_gov`. Добавьте `{"id":"...","name":"...","username":"channel"}` — бот читает `https://t.me/s/channel`, не логинится в ваш аккаунт.

## Команды

- `/start` — chat id и статус
- `/digest` — собрать сейчас
- `/sources` — что сейчас подключено

Пишет только чат из `TELEGRAM_CHAT_ID`.
